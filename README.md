> **English**: A local-first, anime-styled desktop tool for taking and reviewing online-course notes — record your screen and turn it into timestamped AI-recognized notes automatically, fully offline. See the **[English README](README.en.md)**.

---

一款二次元风格网课笔记与复习桌面工具。

产品定位：把「上网课 → 记笔记 → 复习巩固」的完整学习闭环，做成一件**视觉上赏心悦目、数据上完全可控**的工具。界面采用幻想系二次元美学（翁法罗斯主题），核心能力围绕「**录屏自动跟拍成笔记**」与「**AI 理解与复习**」展开。AI 支持**云端 & 本地双模式**——你可以选择接入 DeepSeek / 火山引擎等云端 API，也可以使用本机 Ollama 本地模型，数据自主可控。

> 仓库工程名沿用历史代号 `notestar`（曾用名"笔记星图"），当前产品定位为「二次元网课笔记工具」。

### 60 秒看懂它怎么工作

1. **打开悬浮球**，点一下「录屏笔记」 → 系统获取屏幕录制授权；
2. **正常上网课**，工具在后台每 30 秒自动截一帧画面；
3. **AI（云端或本地模型）** 自动理解画面并用中文写出描述，实时追加到跟拍笔记；
4. 录屏期间每条识别结果以 `🎥 mm:ss` + 截图 + 描述的格式**实时追加到一条跟拍笔记**里；
5. 停止录屏 → 视频按时间轴落盘、会话与笔记互联 → 在笔记页像回放视频一样**按时间码看到所有重点**；
6. 之后**AI 助教**基于笔记上下文随时讲解、生成测验、做知识图谱关联。

整个过程**数据完全可控**——AI 支持云端（DeepSeek / 火山引擎）和本地（Ollama）双模式，笔记与视频文件都保存在你自己的硬盘里。

## 特性一览

**视觉与美学**
- 幻想系二次元 UI（翁法罗斯主题）：粉紫 / 金配色、Bento 卡片、柔和光晕、内联 SVG 动态 Logo 与导航图标，全套由代码直接绘制，无图片依赖
- 主题皮肤系统：内置「黑潮侵蚀」卡牌视觉页（`/heirs`），用 CSS/SVG 实现墨色吞噬、舌状黑火、金红圣火、余烬火星等动态特效，作为皮肤能力的示例与试验场
- 卡片 / 圆角 / 阴影 / 渐变有统一设计令牌，方便换肤

**跟拍笔记（悬浮球录屏）**
- 系统级桌面悬浮球，随时一键开始「录屏笔记」
- 录屏期间每 30s 自动截帧 → **本地 moondream 视觉模型识别画面** → 自动追加带时间轴的图文条目（`🎥 mm:ss` + 截图 + 中文描述）进笔记
- 停止录屏后自动完成会话归档：视频分段、完整时长、笔记绑定，可在笔记页按时间轴回看
- 针对低性能设备优化：默认低分辨率低帧率采集与识别，保证流畅不卡

**AI 双模式（云端 & 本地）**
- 云端模式：支持 DeepSeek / 火山引擎等 API，对话、摘要、测验生成等能力由云端大模型提供
- 本地模式：Ollama 本地模型（moondream 视觉 / qwen2.5 文本 / nomic 语义向量），全部跑在本机
- 全部请求数据自主可控，两种模式可随时切换

**笔记整理与结构化**
- 课程 - 笔记两级组织，Markdown 编写（KaTeX 公式渲染）
- 笔记增强：AI 摘要、扩写、思维导图、自动标题
- 导出 HTML 便于分享存档

**知识网络**
- 课程 / 笔记 / 知识点图谱化展示与关联分析（万帷网）
- 基于本地向量的语义检索，跨课程找得到相关内容

**复习闭环**
- 测验生成（Quiz）、沉浸式复习模式（复习回顾）、到期复习提醒（每小时检查）
- AI 助教对话（教学代理），针对当前笔记上下文提问与讲解

**语音闭环**
- 跟拍 / 课程音频本地转写（faster-whisper + ffmpeg，Windows 内置运行时）
- Windows SAPI 语音朗读，听记复习

**统计与周报**
- 仪表盘：学习时长、笔记量、复习进度等统计与学习周报

## 技术栈

| 层 | 选型 |
|---|---|
| 渲染层 | Vue 3 + TypeScript + Vite |
| 桌面壳 | Electron（主进程 `main.cjs` 直载源码，改主进程即生效） |
| 笔记渲染 | Markdown（marked）+ KaTeX |
| 云端 AI | DeepSeek API / 火山引擎（可选，需自行配置 Key） |
| 本地 AI | Ollama：moondream / qwen2.5 / nomic-embed-text |
| 语音转写 | Python + faster-whisper（内置 `transcribe.py`） |
| 语音合成 | Windows SAPI |
| 存储 | 本地 JSON + 图片/视频文件（`app/data`） |

## 目录结构

```
.
├─ app/                      # Electron 应用主体
│  ├─ electron/              #   主进程 main.cjs、IPC、悬浮球 bubble.html、
│  │                         #   跟拍编排、录屏代理、AI 调用（callAI.cjs）等
│  ├─ src/                   #   Vue 3 渲染层（views / components / store / utils）
│  │  └─ data/               #   主题与角色数据（如 heirs.ts）
│  ├─ public/heirs/          #   黄金裔立绘资源
│  ├─ vendor/                #   内置运行时（python / ffmpeg / whisper 模型，打包用，不入库）
│  ├─ data/ · logs/          #   运行时数据与日志（不入库）
│  └─ package.json
├─ build/                    # 构建资源（图标、便携版启动器源码等）
├─ docs/                     # 架构与技术文档（全景文档、录屏功能总结等）
├─ *.md                      # 各期设计 / 实施 / 测试计划文档
└─ 启动*.bat                 # Windows 一键启动脚本
```

> `data / logs / vendor / Ollama / .workbuddy` 等运行时目录已在 `.gitignore` 中排除，克隆后即为纯净源码。

## 环境要求

- **Windows 10/11 64 位**（悬浮球、录屏、语音闭环依赖 Windows 能力）
- **Node.js ≥ 18**（开发与构建）
- **（可选）Ollama**：不安装则使用云端模式（DeepSeek / 火山引擎），其余功能（笔记、复习、悬浮球录屏成稿为"截图条目"）可正常运行
- **（可选）Python + faster-whisper + ffmpeg**：用于跟拍音频转写；便携发行版已内置，开发环境需自备

## 快速开始

```bash
# 1) 安装依赖
cd app
npm install

# 2) 生产模式运行（先构建渲染层）
npm run build
npm start

# 3) 开发模式（热更新）
npm run electron:dev        # Vite dev server + Electron 主进程
# 或仅渲染层预览：npm run dev
```

首次使用建议：
1. 进入「设置」页，配置 AI 平台（云端 DeepSeek/火山引擎 或 本地 Ollama）；
2. 点悬浮球「录屏笔记」开始第一段跟拍，系统会请求屏幕录制授权；
3. 录完到「笔记整理」页即可看到自动生成的跟拍笔记（带 `🎥` 时间轴条目与截图）。

## 本地 AI 模型（可选）

如果你选择使用本地模式（Ollama），可自行准备模型：

```bash
ollama pull moondream            # 视觉识别：跟拍截帧画面理解
ollama pull qwen2.5:7b-instruct  # 文本：翻译 / 问答 / 摘要 / 测验 / 周报
ollama pull nomic-embed-text     # 语义向量：跨课程检索与知识图谱
```

在「设置 → AI 配置」中可选择云端或本地模式，并配置对应模型。模型未就绪时，跟拍条目的正文会自动降级为「已保存截图」，不阻塞录屏流程。

## 数据与隐私

- 所有笔记、截图、录屏会话均为**本地文件**（默认在 `app/data`），JSON 文本存储、图片按会话归档
- AI 支持**双模式**：云端模式使用 DeepSeek / 火山引擎 API（需自行配置 Key）；本地模式使用本机 Ollama，数据不出本机
- 彻底清理：退出应用后删除 `app/data` 目录即可（注意先备份需要的笔记/视频）

## 视觉体系（简要）

- **配色**：粉 `#FF6B9D` / 紫 `#B794F6` / 蓝 `#4292F5` 主色系 + 金色点缀（翁法罗斯）
- **版式**：圆角卡片（12px / 8px）、胶囊按钮、Bento 布局
- **动效**：内联 SVG + CSS 动画（Logo 齿轮旋转、图标辉光、呼吸光晕），无需外部素材
- **皮肤能力示例**：`/heirs` 黑潮侵蚀页——墨色侵蚀裂纹、黑火随侵蚀度窜高、金红圣火/余烬与侵蚀此消彼长，全部由 CSS/SVG 实时实现

设计令牌与配色规范散见于各期的设计文档（根目录 `*.md`），供换肤参考。
